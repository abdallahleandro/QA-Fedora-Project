# Test Day: CoreOS 45 — Fedora 45

**Data:** 21 a 25 de setembro de 2026

**Página oficial:** https://testdays.fedoraproject.org/testday/27

**Wiki:** https://fedoraproject.org/wiki/Test_Day:Fedora_45_CoreOS

---

## 🖥️ Ambiente de teste

- **Imagem:** Fedora CoreOS 45 (live ISO)
- **VM:** KVM/QEMU via virt-manager
- **Recursos:** 4 vCPU, 8 GB RAM, 60 GB disco
- **Plataforma:** x86_64
- **Teste realizado:** Virtual install

---

## 🧪 Testes realizados

### ❌ Virtual install (Fedora CoreOS 45)

- Instalação via live ISO em VM KVM/QEMU
- Instalação com `coreos-installer` concluída com sucesso
- Após o reboot, o sistema **não exibe prompt de login no VT1**
- Serviços iniciam normalmente (visível no console de boot), mas a tela fica travada
- Console serial também não responde
- Comportamento compatível com bug conhecido relacionado à ausência do `kmscon` no CoreOS
- **Resultado:** FAIL (bug conhecido)

### ✅ Verificação comparativa (Fedora CoreOS 44)

- Para confirmar que o problema era específico da versão 45, testei a versão 44 no mesmo ambiente
- CoreOS 44 instalou e bootou normalmente, exibindo prompt de login
- Sistema funcional, mas requer Ignition para configurar usuário/senha (comportamento esperado)
- **Resultado:** PASS (comportamento esperado)

---

## 📊 Resultado final

| Teste | Status |
|-------|--------|
| Virtual install (F45) | ❌ FAIL (bug conhecido) |
| Virtual install (F44, comparação) | ✅ PASS |

**Bug conhecido no CoreOS 45** — console de login não aparece no VT1.

- O comportamento é **reproduzível** na versão 45
- A versão 44 funciona normalmente, confirmando que é uma regressão específica da 45
